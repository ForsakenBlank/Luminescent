1Luminescent — first UI pass

Built from UI_OVERVIEW.md. Every colour is a theme token (bg_base, bg_card, border, primary…), so the Dark/Light switch in Tweaks restyles every screen at once, along with radius and glow. Type is Geist for UI and Geist Mono for hotkeys, counts and labels; the "hacker" edge is limited to mono caps, 1px borders and a short accent tick under each header. No blur or shadow effects on content; the glow is a single painted halo around the panel.

Dashboard boxes are live: drag a header to move (8px grid), click a header to fold. Theme folder headers also collapse.
